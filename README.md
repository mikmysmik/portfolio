# MIKMYS — Interactive Portfolio

Interactive portfolio website created from scratch as a personal frontend project.

The website combines a custom UI with interactive 3D scenes, animations and responsive layouts.

## Live Demo

https://portfolio-mikmys.vercel.app/

## Technologies

* HTML5
* CSS3
* JavaScript
* Three.js
* GLTF / 3D models
* Responsive Web Design

## Features

* Interactive 3D scenes
* Animated 3D models
* Custom scroll-based interactions
* Responsive desktop and mobile layouts
* Interactive navigation
* Custom UI animations
* Interactive map section

## Project Status

🚧 Currently in development.

The project is continuously being improved and new features and interactions are being added.

## About the Project

This project was created to practice and demonstrate frontend development, JavaScript, Three.js and interactive web experiences.

The website is designed as a concept portfolio for a beauty-related brand.
